# 当前商家、图片和武汉地图

本原型正常启动不需要人工审核。公开目录按近五年的来源证据展示真实门店；归档日期、源记录修改日期、采集日期分别保留，不将收录记录表述为实时营业。

商家资料卡展示已有地址、菜系、招牌菜、参考人均或单品价格、营业时间和电话。详情提供完整菜单、价格来源、经纬度、图片及资料来源。缺失事实明确留空，不复制其他分店价格。旧的照片管理 CLI 仍可处理本地提供的授权图片，但不是浏览、查询或使用地图的前置步骤。

来源图片明确区分店面、菜品和菜品参考图。参考图不冒充该分店实拍；图片无法访问时保留插画封面，不展示破图。

地图加载当前筛选下全部有可靠坐标的门店，不受列表每页 30 条限制。武汉本地地理底图随项目提供；在线街道图不可访问时仍显示武汉的真实主干道路、水域与地名，不显示空白背景。来源、许可和精度范围见 [底图说明](../static/map/README.md)。

卡片可直接定位对应商家；地图弹窗可打开完整资料。缺少坐标的门店保留按店名/地址查询外部地图的入口。选定门店后可以打开导航或拨打已收录的电话，导航及预订交给外部渠道。

运行方式和回归检查见 [项目说明](../README.md)。
